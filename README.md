# WordShift

A React, TypeScript, and Vite word-unscrambling game.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Deployment

The production site is hosted on Vercel and connected to the
[GitHub repository](https://github.com/Dambo-Gideon-Jnr/wordshift-puzzle-game).
Pushes to the production branch trigger a Vercel deployment automatically.

To use a custom domain, add it under **Project Settings → Domains** in Vercel,
then configure the DNS records Vercel displays at your domain registrar.
